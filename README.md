### FlutterDevTools

提供Flutter开发工具

1. 图片资源管理器，便于统一预览/管理图片资源
2. 导入Android资源图片(文件件/压缩包)，导入后自动转化Flutter分辨率格式目录,自动生成图片引用文件和自动同步pubspec.yaml assets数据。
3. 一键删除图片及所有变体
4. 一键重命名图片及所有变体
5. json转dart
6. 生成类序列化方法，构造函数等
7. 文件导航，如点击arb中定义的key，可展示其它语言定义和使用位置。
8. 提取中文为多语言
9. 一键在所有arb文件中删除选中项功能
10. 根据模版arb翻译其它语言arb文件功能
11. 根据arb中选中单个/多个项，将其翻译成其它语言功能
12. 常用Flutter/Dart命令提供快捷方式
