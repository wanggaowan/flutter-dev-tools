### FlutterDevTools

提供Flutter开发工具

1. 图片资源管理器，便于统一预览/管理图片资源
2. 支持导入Android资源图片(文件件/压缩包)，导入后自动生成图片引用文件和自动同步pubspec.yaml assets数据
3. json转dart
4. 生成类序列化方法，构造函数等
5. 文件导航，如点击arb中定义的key，可展示其它语言定义和使用位置。
6. 提取中文为多语言
7. 根据模版arb翻译其它语言arb文件功能
8. 常用Flutter/Dart命令提供快捷方式
