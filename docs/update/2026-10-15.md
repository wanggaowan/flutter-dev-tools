## 导入 Android 图片资源功能

### 功能描述
新增导入 Android 图片目录格式的功能，支持从外部的 Android res 目录或 ZIP 压缩文件中识别并导入不同密度级别的图片资源到 Flutter 项目的指定子目录。

### 实现细节
1. **命令类**: `src/command/import-android-images.ts`
   - **源选择**：使用文件选择对话框让用户选择（支持多选）：
     - Android 密度目录（如 `drawable-mdpi`、`mipmap-xhdpi`）
     - 包含密度目录的父目录（如 `res` 目录）
     - ZIP 压缩文件（包含 Android 密度目录结构）
   - **智能记忆**：
     - 首次使用时，对话框默认打开桌面目录
     - 用户选择后，自动记录该目录的父目录
     - 下次打开对话框时，从上次记录的目录开始
     - 如果上次的目录不存在，回退到桌面目录
     - 记忆仅保存在内存中，插件重启后重置
   - **ZIP 文件处理**：
     - 支持选择 `.zip` 格式的压缩文件
     - 自动解压到系统临时目录（`os.tmpdir()`）
     - 在解压后的目录中查找密度目录
     - 导入完成后自动删除临时解压文件
     - 使用 `adm-zip` 库（纯 JS 实现，无原生依赖）
   - **灵活选择**：
     - 可以直接选择密度目录（如 `drawable-mdpi`、`mipmap-xhdpi`）
     - 也可以选择包含密度目录的父目录（如 `res` 目录）
     - 支持同时选择多个目录和压缩文件
     - 自动过滤非 Android 密度目录的选择
   - **目标目录限制**：必须在配置的 `flutterDevTools.imageSrcPath` 目录及其子目录下执行
   - **忽略变体目录**：在 1.5x、2.0x、3.0x、4.0x 目录及其子目录下不执行
   - 识别 Android 密度目录：drawable-mdpi/hdpi/xhdpi/xxhdpi/xxxhdpi 和 mipmap-mdpi/hdpi/xhdpi/xxhdpi/xxxhdpi
   - 按照映射规则复制文件到选中的目标子目录：
     - mdpi -> 无变体（直接复制到目标目录）
     - hdpi -> 1.5x
     - xhdpi -> 2.0x
     - xxhdpi -> 3.0x
     - xxxhdpi -> 4.0x

2. **命令注册**:
   - 常量: `COMMAND_IMPORT_ANDROID_IMAGES` in `constants.contexts.ts`
   - 在 `package.json` 中注册命令和右键菜单项（对所有文件夹可见）
   - 在 `extension.ts` 中初始化命令类

3. **使用方式**:
   - 在 Flutter 项目视图中，右键点击 `assets/images` 或其非变体子目录（如 `assets/images/icons`）
   - 选择"导入 Android 图片资源"菜单项
   - 在弹出的对话框中选择一个或多个项目：
     - 方式 1：直接选择密度目录（可多选），如 `drawable-mdpi`、`drawable-xhdpi`、`mipmap-xxhdpi`
     - 方式 2：选择包含密度目录的父目录，如 `res` 目录
     - 方式 3：选择 ZIP 压缩文件（包含完整的 Android res 目录结构）
     - 方式 4：混合选择，同时选择目录和压缩文件
   - 插件会自动：
     - 验证选中目录是否在正确的路径下
     - 检查是否不在变体目录中
     - 如果是 ZIP 文件，先解压到临时目录
     - 识别所有有效的密度目录（自动忽略非密度目录）
     - 按规则复制图片到选中的目标子目录
     - 跳过已存在的文件
     - 清理临时解压文件
     - 显示导入结果通知

4. **依赖库**:
   - `adm-zip`: 用于解压 ZIP 文件的轻量级纯 JavaScript 库
