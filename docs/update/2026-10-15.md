## 自动生成图片引用方法

### 功能描述
新增根据 `imageSrcPath` 目录下的图片文件自动生成 Dart 引用类的 getter 方法的功能。当导入新图片或监听到新目录时，会自动在配置的 `imagesFilePath` 路径下创建或更新图片引用类（默认类名为 `Images`），为每个图片生成静态 getter 方法。

### 实现细节
1. **工具类**: `src/utils/image-reference-generator.ts` (新建)
   - **图片路径转换**：将图片路径转换为驼峰命名的方法名
     - 去掉 `imageSrcPath` 前缀
     - 去掉文件扩展名
     - 将特殊字符（/, @, -, .）替换为下划线
     - 使用 `lowerCamelCase` 工具函数转换为驼峰命名
   - **类管理**：
     - 检查 Images 类是否存在，不存在则创建
     - 类的基本格式：`class Images { Images._inner(); }`
   - **方法生成**：
     - 生成格式：`static String get methodName => 'image/path.png';`
     - 自动去重：检查方法是否已存在，避免重复生成
     - 变体去重：对于同一图片的不同变体（1.5x, 2.0x等），只生成一个方法
   - **批量处理**：
     - 递归扫描目录下所有图片文件
     - 支持增量生成（只添加新方法）
     - 支持重新生成（清空后重建）

2. **集成到导入流程**:
   - 在 `import-android-images.ts` 中，导入图片成功后自动生成引用
   - 显示生成结果通知

3. **集成到监听器**:
   - 在 `image-asset-watcher.ts` 中，监听到新目录创建时自动生成该目录下图片的引用
   - 与 pubspec.yaml 同步功能协同工作

4. **生成示例**：
   ```dart
   // 图片路径: assets/images/ht/repair/fuwu.png
   // 生成的方法:
   static String get htRepairFuwu => 'assets/images/ht/repair/fuwu.png';
   
   // 图片路径: assets/images/icons/user-avatar@2x.png
   // 生成的方法:
   static String get iconsUserAvatar2x => 'assets/images/icons/user-avatar@2x.png';
   ```

### 相关文件
- `src/utils/image-reference-generator.ts` (新建)
- `src/command/import-android-images.ts` (修改)
- `src/watcher/image-asset-watcher.ts` (修改)

## 自动同步图片资源目录到 pubspec.yaml

### 功能描述
新增自动监听 `imageSrcPath` 配置目录下子目录变化的功能。当在该目录下创建或删除子目录时，会自动更新项目根目录的 `pubspec.yaml` 文件中的 `flutter.assets` 节点，添加或移除对应的相对路径。

### 实现细节
1. **工具类**: `src/utils/pubspec-utils.ts` (新建)
   - 提供读取和写入 `pubspec.yaml` 的方法
   - 使用 `yaml` 库进行 YAML 解析和序列化
   - 支持添加、移除和同步资源目录到 assets 列表
   - 所有路径均转换为相对于项目根目录的 Unix 风格路径（使用正斜杠）

2. **监听器**: `src/utils/image-asset-watcher.ts` (新建)
   - 使用 VSCode 的 `FileSystemWatcher` 监听 `imageSrcPath` 目录下的直接子目录变化
   - 监听到目录创建时，自动添加到 `pubspec.yaml` 的 assets 列表
   - 监听到目录删除时，自动从 `pubspec.yaml` 的 assets 列表中移除
   - 支持配置变更时重新初始化监听器
   - 提供同步方法，确保 assets 列表与实际目录结构一致

3. **集成到插件**:
   - 在 `extension.ts` 的 `activate` 函数中初始化监听器
   - 监听 `flutterDevTools.imageSrcPath` 配置变更，自动重新初始化
   - 在 `deactivate` 函数中清理监听器资源

4. **使用方式**:
   - 无需手动操作，插件会自动监听配置的 `imageSrcPath` 目录（默认为 `assets/images`）
   - 在该目录下创建新文件夹时，会自动添加到 `pubspec.yaml` 的 assets 节点
   - 删除该目录下的文件夹时，会自动从 `pubspec.yaml` 的 assets 节点移除
   - 每次添加或移除都会显示通知提示用户

### 相关文件
- `src/utils/pubspec-utils.ts` (新建)
- `src/utils/image-asset-watcher.ts` (新建)
- `src/extension.ts` (修改)

## 导入 Android 图片资源功能

### 功能描述
新增导入 Android 图片目录格式的功能，支持从外部的 Android res 目录或 ZIP 压缩文件中识别并导入不同密度级别的图片资源到 Flutter 项目的指定子目录。导入前会显示预览对话框，让用户确认和重命名图片，并实时检测文件名冲突。

### 实现细节
1. **命令类**: `src/command/import-android-images.ts`
   - **源选择**：使用文件选择对话框让用户选择（支持多选）：
     - Android 密度目录（如 `drawable-mdpi`、`mipmap-xhdpi`）
     - 包含密度目录的父目录（如 `res` 目录）
     - ZIP 压缩文件（包含 Android 密度目录结构）
   - **智能记忆**：
     - 首次使用时，对话框默认打开桌面目录
     - 用户选择后，自动记录该目录的父目录
     - 下次打开对话框时，从上次记录的目录开始
     - 如果上次的目录不存在，回退到桌面目录
     - 记忆仅保存在内存中，插件重启后重置
   - **ZIP 文件处理**：
     - 支持选择 `.zip` 格式的压缩文件
     - 自动解压到系统临时目录（`os.tmpdir()`）
     - 在解压后的目录中查找密度目录
     - 导入完成后自动删除临时解压文件
     - 使用 `adm-zip` 库（纯 JS 实现，无原生依赖）
   - **灵活选择**：
     - 可以直接选择密度目录（如 `drawable-mdpi`、`mipmap-xhdpi`）
     - 也可以选择包含密度目录的父目录（如 `res` 目录）
     - 支持同时选择多个目录和压缩文件
     - 自动过滤非 Android 密度目录的选择
   - **目标目录限制**：必须在配置的 `flutterDevTools.imageSrcPath` 目录及其子目录下执行
   - **忽略变体目录**：在 1.5x、2.0x、3.0x、4.0x 目录及其子目录下不执行
   - 识别 Android 密度目录：drawable-mdpi/hdpi/xhdpi/xxhdpi/xxxhdpi 和 mipmap-mdpi/hdpi/xhdpi/xxhdpi/xxxhdpi
   - 按照映射规则复制文件到选中的目标子目录：
     - mdpi -> 无变体（直接复制到目标目录）
     - hdpi -> 1.5x
     - xhdpi -> 2.0x
     - xxhdpi -> 3.0x
     - xxxhdpi -> 4.0x
   - **导入预览**：
     - 收集所有待导入的图片后，按文件名进行分组（相同文件名不同变体合并为一组）
     - 按 drawable 和 mipmap 类型分为两个独立列表展示
     - 使用 WebView 对话框显示预览界面
     - 左侧显示真实图片缩略图（48x48px），右侧显示可编辑的文件名输入框
     - 缩略图使用第一个变体的源文件路径，即使存在冲突也正常显示
     - 用户可以修改文件名，系统会实时检测冲突并显示红色警告
     - 冲突分为两类，分别展示提示文本，右侧各有一个勾选框：
       - 批次内同名冲突：勾选则导入最后一个同名文件，否则导入第一个同名文件
       - 目标目录已存在同名文件：勾选则覆盖原文件，否则跳过导入
     - 点击"取消"则放弃本次导入操作

2. **命令注册**:
   - 常量: `COMMAND_IMPORT_ANDROID_IMAGES` in `constants.contexts.ts`
   - 在 `package.json` 中注册命令和右键菜单项（对所有文件夹可见）
   - 在 `extension.ts` 中初始化命令类

3. **使用方式**:
   - 在 Flutter 项目视图中，右键点击 `assets/images` 或其非变体子目录（如 `assets/images/icons`）
   - 选择"导入 Android 图片资源"菜单项
   - 在弹出的对话框中选择一个或多个项目：
     - 方式 1：直接选择密度目录（可多选），如 `drawable-mdpi`、`drawable-xhdpi`、`mipmap-xxhdpi`
     - 方式 2：选择包含密度目录的父目录，如 `res` 目录
     - 方式 3：选择 ZIP 压缩文件（包含完整的 Android res 目录结构）
     - 方式 4：混合选择，同时选择目录和压缩文件
   - 插件会自动：
     - 验证选中目录是否在正确的路径下
     - 检查是否不在变体目录中
     - 如果是 ZIP 文件，先解压到临时目录
     - 识别所有有效的密度目录（自动忽略非密度目录）
     - 收集所有待导入的图片信息
     - 显示预览对话框，展示图片列表和文件名输入框
     - 用户可以在输入框中修改文件名，系统实时检测冲突并显示红色警告
     - 确认无冲突后点击"确认导入"按钮
     - 按规则复制图片到选中的目标子目录
     - 跳过已存在的文件
     - 清理临时解压文件
     - 显示导入结果通知

4. **依赖库**:
   - `adm-zip`: 用于解压 ZIP 文件的轻量级纯 JavaScript 库
