## 修复图片 doc hover 中链接与图片无法展示

### 问题描述
在 Dart 代码中 hover `Images.xxx` 时，浮层里的文件超链接和图片预览都显示不出来。

### 原因分析
`src/provider/image-doc-hover-provider.ts` 用绝对路径拼接 markdown：

```ts
imagePath = pathUtils.join(workspaceFsPtah, relPath);
openPath = pathUtils.join(workspaceFsPtah, element);
```

存在一个问题：

1. 裸路径（无论绝对还是相对）在 markdown 中不做 URL 编码，项目路径含空格（如 `ide plugin`）时会被 markdown 解析成「链接目标 + title」，Windows 下反斜杠还会被当作转义字符。

### 实现细节
- 直接使用 `vscode.Uri.file(绝对路径).toString()` 生成 `file://` URI，由 VS Code 完成百分号编码与平台路径规范化。
- 为 `MarkdownString` 设置 `baseUri = document.uri`，保证相对引用也有明确的解析基准。
- 保留 `isTrusted = true`；插件在 `package.json` 中声明 `untrustedWorkspaces.supported: false`，工作区必然是受信状态，`file://` 图片可以正常渲染。

生成的 markdown 由：

```md
[assets/images/home/icon.png](Users/xxx/flutter%20demo/assets/images/home/icon.png)

![](Users/xxx/flutter%20demo/assets/images/home/icon.png)
```

修正为：

```md
[assets/images/home/icon.png](file:///Users/xxx/flutter%20demo/assets/images/home/icon.png)

![](file:///Users/xxx/flutter%20demo/assets/images/home/icon.png)
```
