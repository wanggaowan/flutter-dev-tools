## 新增 l10n arb 文件变化自动执行 gen-l10n 功能

### 需求描述
当项目中 `l10n.yaml` 指定的 `template-arb-file` 对应的 arb 文件**保存后**,自动执行 `flutter.task.genl10n` 命令。同时监听 `l10n.yaml` 配置文件的变化,当配置变更时重新初始化 arb 文件的监听。

### 实现细节
- 监听器：新增 `L10nArbWatcher` 类，在插件激活时启动
- 配置读取：从 `l10n.yaml` 中解析 `arb-dir`、`template-arb-file` 和 `project-dir` 配置项，确定需要监听的 arb 文件路径
- 双重监听机制：
  - **arb 文件监听**：使用 VS Code 的 `FileSystemWatcher` 监听 arb 文件的变化，可以捕获所有写入操作（包括编辑器保存、`fs.writeFileSync`、外部工具修改等）
  - **配置文件监听**：使用 `FileSystemWatcher` 监听 `l10n.yaml` 文件的变化，当配置文件修改时自动重新初始化 arb 文件监听器
- 生命周期管理：在插件停用时正确释放所有监听器资源

### 相关文件
- `src/watcher/l10n-arb-watcher.ts` (新增)
- `src/extension.ts` (修改)

## 新增重命名图片及所有变体功能

### 需求描述
在资源管理器中选中一张图片，右键即可重命名该图片，同时重命名它在变体目录（`1.5x`、`2.0x`、`3.0x`、`4.0x` 等）下的同名图片。

### 实现细节
- 入口：`Flutter` 子菜单（`flutterDevTools.explorerContext`）新增命令「重命名图片及所有变体」，仅在图片扩展名（png/jpg/jpeg/webp/gif/svg/bmp）时出现；命令接收 VS Code 传入的 `uri`，支持单文件重命名。
- 变体识别：复用 `ImageVariantUtils.collectVariants(imageFilePath)`，按 Flutter 约定处理，变体目录是图片所在目录的直接子目录（目录名匹配 `^\d+(\.\d+)?x$`）。
- 重命名流程：
  1. 弹出输入框让用户输入新文件名（不含扩展名），支持默认值为原文件名
  2. 验证文件名只能包含字母、数字、下划线和连字符
  3. 收集所有需要重命名的变体文件
  4. 检查目标文件是否已存在，如有冲突则提示用户确认覆盖
  5. 逐个执行重命名操作，使用 `vscode.workspace.fs.rename()` 并允许覆盖
  6. 显示重命名结果统计
- 引用清理：重命名后文件路径变更会触发 `ImageAssetWatcher` 的删除事件，由它自动移除旧的引用方法；同时监听器检测到新文件后会生成新的引用方法。

### 相关文件
- `src/command/rename-image-variants.ts` (新增)
- `src/constants.contexts.ts` (修改)
- `src/extension.ts` (修改)
- `package.json` (修改)
