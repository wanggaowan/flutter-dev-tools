## dart/json 高亮增加括号与运算符

### 需求描述
dart、json 的高亮把 `{}`、`[]`、`()`、`;`、`,` 等关键符号和运算符也纳入着色。

### 实现细节
- dart 分词新增 `punct` 组（`{} [] () ; , . :`）与 `op` 组（`=> ?. ?? == != <= >= && || ++ -- += -= *= /= %= ~/ + - * / % = < > ! & | ^ ~ ?`，长运算符优先匹配）；json 新增 `punct` 组（`{} [] : ,`）。
- 新增 `tok-punct`、`tok-op` 两类配色：深色 `#d7ba7d` / `#c586c0`，浅色 `#0431fa` / `#af00db`。
- 括号、分隔符仍排在字符串/数字之后匹配，数字中的小数点、字符串内的符号不会被误判。

### 相关文件
- `media/file-template/script.js` (修改)
- `media/file-template/styles.css` (修改)

## 调亮高亮配色中的普通文本

### 需求描述
内容区非关键字文本偏暗，观感接近注释，需要适当调亮，参考 vscode 配色。

### 实现细节
- 新增 `--tok-plain` 变量并显式作用于高亮层及其内部 `code`，避免普通文本继承到偏暗的颜色：深色 `#e4e4e4`、浅色 `#1f1f1f`。
- 光标颜色、输入法组合输入时的文字颜色同步改用 `--tok-plain`。
- 其余 token（注释、字符串、关键字、数字、注解、json key）保持 vscode 官方 Dark+/Light+ 取值不变，正常文本与注释的明暗差异更明显。

### 相关文件
- `media/file-template/styles.css` (修改)

## 内容区去掉代码块背景色

### 需求描述
内容编辑区域不要出现「代码块」背景色，保持与面板其它区域一致。

### 实现细节
- VSCode 默认样式会给 Webview 里的 `pre`/`code` 涂 `--vscode-textCodeBlock-background`，高亮层的 `pre` 叠加后表现为一块独立的代码背景；在 `.editor-highlight` 及其内部 `code` 上显式设置 `background-color: transparent` 覆盖。
- 行号栏、代码容器、空状态提示同步改为透明背景，不再绘制 `--vscode-editor-background`，内容区完全跟随面板背景。

### 相关文件
- `media/file-template/styles.css` (修改)

## 内容编辑区按文件后缀语法高亮

### 需求描述
内容展示界面根据文件后缀使用不同语言的编辑器（类似 vscode 代码编辑器的着色效果），只支持 dart、json、yaml（含 yml），其它后缀按纯文本处理。

### 实现细节
- 不引入第三方编辑器依赖，采用「高亮层 + 透明文字 textarea」叠加方案：`<pre><code>` 渲染带 token 的富文本，textarea 覆盖其上并设置 `color: transparent`、保留 `caret-color`；两层共用字体、字号、行高、padding、tab-size 且不换行（`white-space: pre`），光标位置与高亮文字完全重合。
- textarea 负责输入、选区与滚动；`scroll` 事件把 scrollTop/scrollLeft 同步给高亮层，行号栏同步 scrollTop。可编辑时才渲染高亮与行号，纯文本/未选中文件时清空。
- 行号栏按内容行数实时重算并随滚动同步，尺寸自适应行数位数。
- 分词为纯正则实现（命名分组匹配 + 逐段 HTML 转义）：dart 支持行注释、块注释、字符串（`r'...'`、`'''`/`"""` 多行）、注解、关键字、数字；json 支持注释、字符串、布尔/null、数字，字符串后跟冒号时判定为 key；yaml 按行处理，支持注释、key、引号字符串、布尔/null、数字，引号内的 `#` 不当作注释，`- key: value` 列表项同样着色；其它后缀只做转义。
- token 颜色使用自定义调色板（深/浅两套 CSS 变量），按当前主题切换 `body.light`：初始主题由插件在初始数据中下发 `isDarkTheme`，主题变化时通过 `onDidChangeActiveColorTheme` 回传 `changeTheme` 实时切换。
- 输入法组合输入期间（`compositionstart`/`compositionend`）临时显示原始文字并隐藏高亮层，避免透明文字导致中文输入不可见。
- 切换选中文件时重置滚动位置，保证高亮层、行号栏与 textarea 起点一致。

## 新增创建模板文件功能（移植 IntelliJ 插件）

### 需求描述
参照 IntelliJ 插件 `actions/filetemplate` 目录的实现，将「创建模板文件」功能移植到 vscode 插件，界面改为 Webview 实现。功能包含：模板列表管理、模板内文件/目录结构管理、文件内容编辑、占位符填充、模板导入导出、按模板批量创建文件。

### 实现细节
- 模板数据通过 `context.globalState` 持久化（对齐 IntelliJ 使用应用级 PropertiesComponent 的做法），首次使用时写入 6 个内置模板，并用版本号控制后续升级新增的默认模板，避免覆盖用户改动。
- 内置模板内容与 IntelliJ 插件中的 `template/*.kt` 保持一致（page、simplePage、formPage、simpleFormPage、viewPagerPage、simpleViewPagerPage）。
- Webview 采用 `media/file-template` 下的 `index.html + styles.css + script.js` 静态资源，面板 HTML 读取后注入 CSP nonce、资源 URI 和初始数据；初始数据通过 `type="application/json"` 的 data block 传递，避免 `postMessage` 与脚本加载的时序问题。
- 界面分为模板列表、文件结构树、内容编辑三栏，底栏展示创建位置与「同名文件存在时创建副本」开关；模板与文件节点的右键菜单支持重命名、删除、复制模板、上移/下移/移到首尾、切换模板「仅作为分类/同时作为目录」。
- 创建流程：解析模板内容中的 `#xxx#` 占位符，内置占位符 `#DATE#`、`#TIME#`、`#DATETIME#`、`#USER#` 由插件自动填充，其余占位符在 Webview 弹窗中录入后随创建消息发送。
- 文件创建逻辑对齐 IntelliJ：模板可额外创建以模板名命名的目录，支持嵌套目录；同名文件在未勾选创建副本时报错，勾选后按 `name_1.dart` 规则递增生成，最多尝试 20 次；创建内容优先使用界面中未点「应用」的临时编辑内容。
- Webview 中任意的模板结构改动会立即回传保存（对齐 IntelliJ 取消弹窗也保存模板改动），但临时编辑内容不持久化，仅在创建时使用。
- 导入支持单个模板对象或模板数组的 JSON 文件，导出使用系统保存对话框，导出前统一清洗界面状态字段。
- 命令注册到浏览器右键 Flutter 子菜单和命令面板（`flutterDevTools.isFlutterProject` 时可用），目标目录取右键选中的目录，选中文件时取其所在目录，无上下文时取工作区根目录。
- 模板列表只展示模板名称，不展示目录图标（与 IntelliJ 的普通列表保持一致）；文件结构树仍保留目录/文件图标。
