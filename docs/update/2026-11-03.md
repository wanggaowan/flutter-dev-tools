## 新增需求 prompt 模板

### 需求描述
提供一个可直接复制的需求描述模板，让每次向 AI 提需求时都包含背景、范围、期望行为、约束、验收和参考，减少 AI 全仓扫描与只实现主流程的问题。

### 实现细节
- 模板分为背景与目标、范围、期望行为、约束、验收、参考六部分，范围要求写明可修改/只读/不涉及的具体路径。
- 验收固定要求 `npm run check-types`、`npm run lint` 和 F5 手验项。
- 附一个 `.arb` 排序命令的填写示例，以及六条使用说明（一个需求一次提交、边界要写、先方案后代码等）。

### 相关文件
- `docs/需求模板.md` (新增)

## AGENTS.md 补充命令与禁区清单

### 需求描述
在 AGENTS.md 中补全常用命令、验证方式和禁止项，减少 AI 协作时的误操作（改依赖、动构建产物、漏改命令注册等）。

### 实现细节
- 新增「常用命令与验证」：列出 `check-types`、`lint`、`compile`、`package`、`watch`、`test`，明确改完至少执行前两项；`npm test` 仅有一个示例用例，不作为验证依据；列出必须按 F5 手动验证的功能（菜单显示条件、Project 视图与 webview、命令面板可见性、涉及文件读写的功能）。
- 新增「禁区」：禁止改依赖与 `package-lock.json`、禁止手改 `dist/out/*.vsix`、禁止改或重命名已有命令 ID 并明确新增命令的三处同步项、禁止动清单契约字段、禁止硬编码阿里翻译 AK/SK、禁止无关文件改动与顺手重构。
- 原「rules」「在你完成一项任务之前」顺延为第 3、5 节。

### 相关文件
- `AGENTS.md` (修改)
