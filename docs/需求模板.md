# 需求 Prompt 模板

把下面内容复制到对话里，按需删减。括号内是填写说明，提交前删掉。

---

## 需求：<一句话说清要做什么>

### 1. 背景与目标

- 现象：<现在是什么表现，或为什么需要这个功能>
- 目标：<改动生效后应该变成什么样>

### 2. 范围

- 涉及：<允许修改的目录/文件，如 `src/provider/`、`package.json`>
- 只读参考：<需要看但不要改的文件>
- 不涉及：<明确排除的目录，如 `media/file-template/`、`src/command/create-file-template.ts`>

### 3. 期望行为

- 触发：<什么时候生效，如「右键 .arb 文件」「命令面板执行」>
- 正常路径：<主流程的输入与输出>
- 边界/异常：<空值、文件不存在、同名冲突、多项目结构等要如何处理>

### 4. 约束

- 不要改动：<接口、类名、已有命令 ID、配置项 key 等>
- 不要引入：<新依赖、新抽象层、配置文件>
- 复用：<应该复用的已有工具方法或类>

### 5. 验收

- 命令：`npm run check-types`、`npm run lint`
- F5 手验：
  - [ ] <菜单/命令面板中是否按 `when` 条件显示>
  - [ ] <主流程在真实 Flutter 项目上的结果>
  - [ ] <异常/边界场景的表现>

### 6. 参考

- 历史改动：`docs/update/<日期>.md`
- 相关规范：`AGENTS.md` 第 2、3、4 节

---

## 示例

> 需求：`.arb` 文件右键菜单增加「按 key 排序」命令
>
> 1. 背景与目标：现象是 arb 文件 key 顺序随编辑变得混乱，目标是右键一次后按字母序重排并保留缩进与注释。
> 2. 范围：涉及 `src/command/`、`src/utils/`、`package.json`；不涉及 `media/`、多语言翻译相关命令。
> 3. 期望行为：触发条件是资源管理器中右键 `.arb` 文件；正常路径为解析 JSON、按顶层 key 排序、两空格缩进写回；边界情况为文件非法 JSON 时提示错误且不写文件，空文件直接跳过。
> 4. 约束：不改已有命令 ID，不引入 JSON 库，复用 `src/utils` 中现有的格式化/写文件方法。
> 5. 验收：`check-types` + `lint` 通过；F5 在示例项目中对 `app_zh.arb` 排序，验证菜单只在 `.arb` 上出现、非法 JSON 不破坏原文件。
> 6. 参考：IntelliJ 插件 `actions/arb/SortArbAction.kt`；规范见 `AGENTS.md`。

## 使用说明

1. 一次只提一个需求；跨模块的改动拆成多条，分次提交。
2. 范围要写具体路径，比「你自己找找」准确得多，也能防止 AI 全仓扫描。
3. 边界/异常不写，AI 通常只实现主流程。
4. 验收必须包含 F5 手验项：`tsc` 和 `eslint` 通过不代表功能正确。
5. 需求较大时先让 AI 出方案，确认后再写代码。
6. 完成后核对 `dist/` 未被提交、`docs/update` 已记录、新增命令的三处注册齐全。
